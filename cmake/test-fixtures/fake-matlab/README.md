# fake-matlab — stub MATLAB tree (NOT a real MATLAB)

A minimal fake MATLAB installation used to verify the **CMake wiring** of the
MATLAB mex backend with no MATLAB present: that `find_package(Matlab)` +
`matlab_add_mex` + the `libmwfftw3` finder resolve and produce a `<mod>mex.<ext>`
exporting only `mexFunction`. It does **NOT** emulate MATLAB and proves **nothing**
about runtime or numerical correctness — that is the job of `../MATLAB-HOST-SMOKE.md`.

The stub headers are self-authored to match our mex sources; the stub `.so` are
generated by `../make-fake-matlab.sh` (and gitignored). `libmwfftw3.so.3` is a copy
of the real system `libfftw3` (same ABI) named with the versioned suffix MATLAB
actually uses, so the finder's versioned-name path is exercised.
